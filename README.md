# ProductLens

Analyse any product down to its depth, built for PMs who need more than a surface-level teardown.

🔗 **Live demo:** https://productintel.bolt.host

## What it does

Point ProductLens at a product and get back a structured, in-depth analysis - the kind of teardown a product manager would actually want: positioning, mechanics, likely tradeoffs, and what's driving the decisions behind it, rather than a generic marketing-style summary. Built for PM work - competitive research, case studies, and understanding *why* a product is built the way it is, not just *what* it does.

## Status

Built and deployed as a Bolt project; the live app is the source of truth. This repository tracks the project on GitHub as a reference point - see the demo link above for the actual product.
